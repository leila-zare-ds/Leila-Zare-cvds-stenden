# Dental Practice Management System

This project is a Python-based redevelopment of selected parts of an older Dental Practice Management System.

The original application was developed using Delphi and SQL Server and was previously implemented in a real hospital environment.

I am currently rewriting parts of the original application using Python. The current version represents work in progress and does not yet include all features of the original system.

**Important:** All patient records and personal information displayed in the screenshots are entirely fictional and are used only for demonstration purposes.

## Technologies
- Python
- Tkinter
- SQL Server
- pyodbc

## Current Status
The Python redevelopment is ongoing. The screenshots demonstrate some of the implemented modules and interfaces.
